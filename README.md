# selfcollege-waba

**把课件变成真正能跟着学的讲义。**

一份资料，两份互补的学习材料：逐页保留原稿的对照版，以及讲清概念、拆开公式、配齐练习与答案的精讲版。可以从一门大学课程开始，也可以用于自己的系统学习。

## 你会得到什么

| 你提供 | selfcollege-waba 帮你完成 |
| --- | --- |
| 一讲 PDF 课件 | 逐页对照 PDF ＋ 零基础精讲 PDF |
| 课件和课堂转写 | 将老师实际讲到的解释和重点批注到对应原页 |
| 课程大纲和多讲资料 | 课程地图、资料索引与学习档案 |
| 一个没看懂的公式、图表或概念 | 回到原页，逐步解释，并核对适用条件 |
| 已有学习档案 | 接续当前课程的进度、术语和个人偏好 |

对照版保留原稿全部页面、图表和公式；精讲版按知识模块解释“是什么、为什么、怎么用”，提供基础、应用和挑战练习及答案。默认采用清晰的深蓝与青绿色版式，可按你的语言、基础和阅读习惯调整。

## 开始使用

[**下载 selfcollege-waba.zip**](https://github.com/RivanXU/selfcollege-waba/releases/latest/download/selfcollege-waba.zip)，解压后得到同名文件夹。请保留整个文件夹，里面的参考文档和 PDF 工具也是 Skill 的组成部分。

### 在支持本地 Skill 的 Codex 中使用

把 `selfcollege-waba` 文件夹放到当前学习项目的 `.agents/skills/` 内，即：

```text
你的学习项目/
└── .agents/
    └── skills/
        └── selfcollege-waba/
            ├── SKILL.md
            ├── agents/
            ├── references/
            └── scripts/
```

这是仅对当前项目生效的安装方式。需要自己所有项目都可用时，可放入个人的 `~/.agents/skills/`。同一作用范围保留一份安装即可。若技能列表尚未更新，先检查目录层级和文件是否齐全，再刷新或重新打开技能列表。安装位置以[官方 Skill 文档](https://learn.chatgpt.com/docs/build-skills)为准。

上传课件，然后发送：

> 请使用 $selfcollege-waba，帮我学习这份课件。我希望用中文讲解并保留英文术语，请生成逐页对照 PDF 和零基础精讲 PDF。

首次使用只需说明课程、想学习的部分和讲解语言；学校、专业及学习阶段都可以选填。已经说明的信息不必重复填写。

### 在其他 AI 对话中使用

如果你的应用有 Skill 导入入口，按该应用说明导入完整文件夹或 ZIP。不同应用、账户的入口与文件能力可能不同，本包不承诺所有产品都支持直接安装。

没有导入入口时，打开[完整学习提示词](references/master-prompt.md)，把其中“可复制提示词”的内容与课程资料一起交给 AI。这种方式可使用教学流程；能否直接生成并下载 PDF，取决于所用应用是否具备文件读取和生成能力。仅支持文字的应用可以先交付可导出的讲义内容。

**无需申请 API Key，也无需部署服务器。** 你仍需自行使用具备相应能力的 AI 应用，其账户权限、使用额度或订阅费用由该应用决定。

## 常用说法

- “这是课程大纲和全部课件，先建立课程地图，不必生成所有讲义。”
- “只解释第 8 页的公式，先讲符号，再逐步推导。”
- “补充这份课堂转写，把有依据的重点加到对应页面。”
- “这门课以后多讲推导，练习答案放在题目后面。”
- “这是上次的学习档案，请继续下一讲。”

## 资料和进度

课件、转写、输出文件和学习档案保存在你的课程空间，与 Skill 文件夹分开。跨对话接续依赖实际保存且可访问的档案；生成讲义不会被记录为你已经掌握课程。

本包不包含联网激活、作者服务器或遥测程序。你使用的 AI 应用如何处理上传资料，仍取决于该应用自己的设置和条款。课件与教材的原有版权不因使用本工具而改变。

## PDF 工具

完整生成器位于 [`scripts/render_study_pdfs.py`](scripts/render_study_pdfs.py)，输入格式和可调整样式见 [PDF 使用说明](references/pdf-style.md)。通常可以直接让 AI 准备内容并调用它，无需自己编写内容清单。

本地运行时需要 Python 环境，以及 [`requirements.txt`](requirements.txt) 中的两个依赖。建议让 AI 在当前项目的独立环境内安装缺少的依赖。本包只提供排版工具；翻译、讲解和答案由 AI 根据你的资料撰写，仍需核对来源和计算。复杂数学、特殊文字方向或特别密集的页面可能需要其他排版工具。
