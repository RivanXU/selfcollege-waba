# Course acceptance ledger

Copy this template into the learner's course workspace for a lecture pack or its revision. Expand the tables to account for every requested source page, original homework stem/subpart, and final output page. Record checks actually performed; an empty cell or an intended check is not evidence. This is a review record, not a semantic score or proof of learner mastery.

## Module route

Core modules own consecutive physical pages in the requested source order. Within each source file, ranges are contiguous, increase monotonically, and collectively account for every requested page, including covers and progressive reveals. A source page has one primary module; later references to it are labeled back-links. Mark unreadable pages as gaps at their correct position.

## Every final output page

Render the final files and inspect every page at reading size. Record a real reviewed image path and the observed result. Companion checks compare corresponding objects and source/translation content; equal page counts and viewports are separate structural checks. Guide checks include fractions/scripts, nearby symbol definitions, derivation reasons, tables/images, fonts, spacing and pagination.

## Delivery decision

- Coverage reconciliation: requested and recorded source pages; homework stems/subparts; final pages.
- Content checks: calculations or reasoning verified, notation/conditions checked, conflicts resolved or located.
- Structural checks: consecutive module routing, source/companion count and order, output references.
- Unresolved limitations: exact locations, effect on learning/delivery, and next action.
- Deliverable status: accepted for the recorded scope, partial with explicit gaps, or blocked.

Apply the recorded acceptance criteria. Mark a pack accepted only after the recorded scope is accounted for and the actual checks support that decision. Preserve evidence and unrelated chapters when revising; recheck pages affected by content, pagination, reference or layout changes.
