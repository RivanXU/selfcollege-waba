# 个性化与学习偏好

## 了解学习者

先使用当前对话和本人的可访问档案。缺少信息时简短了解本次课程与章节、学习阶段、已有基础和讲解语言；学校或机构、专业或兴趣方向可以自愿补充。自学者和不提供学校信息的人同样适用，不为填满表格推迟可开展的工作。

课程归属影响资料选择时先确认。文件封面可以说明文件来自哪门课，不能证明使用者就读该学校。没有基础信息时从核心概念开始，根据实际问答调整解释深度，不给学习者预设能力标签。

## 偏好的作用范围

优先级为：**本次明确要求 → 当前课程偏好 → 当前学习者通用偏好 → 默认设置**。偏好调整仍需保持来源诚实、翻译准确和资料隔离；只有会改变任务实质的歧义才询问。

| 使用者表达 | 保存范围 |
|---|---|
| “这次简洁一点” | 仅本次任务。 |
| “这门课以后多讲推导” | 本人的当前课程档案。 |
| “我以后所有课程都用紫色” | 本人的通用偏好。 |
| “修改我安装的 selfcollege-waba” | 本人有权限编辑的安装副本。 |

持续适配来自已保存的偏好与实际学习反馈，不表示后台训练了模型，也不保证无限记忆。跨对话接续以能实际访问的档案为准。

## 保存位置与内容

个人偏好和课程档案放在 **Skill 目录之外、属于当前学习者的可持久保存位置**。只读取当前学习者的档案；多人共用账户或项目且归属不明时先区分学习者。

个人偏好可记录自愿提供的背景、首选语言、术语展示、解释详略、练习与答案展示方式、视觉样式及默认交付格式。课程档案保存该课程的教师要求、资料来源、术语口径、具体卡点和学习进度。记录确有用途的内容，不必收集学校等非必要个人字段。

能保存文件时实际写入并说明位置；环境无法持久保存时提供可复制的档案摘要，让用户在后续对话中继续使用，不能声称已经永久记住。

PDF 视觉偏好可另存为课程或个人目录中的 `pdf-style-overrides.json`，通过生成器的 `--style` 参数使用；不同语言的页面标签用内容清单中的 `labels` 指定。字段和限制见 [PDF 样式参考](pdf-style.md)。日常偏好调整不需修改 Skill 内的默认文件。

## 学科与语言

使用“框架—细讲—分层练习—复习”的共同流程，教学对象随资料变化：没有公式时解释论证链，没有数值例题时安排有资料依据的概念辨析或文本分析。明确已掌握的基础可以略讲，但逐页原文对照仍须完整覆盖当前范围。

英文原稿配中文讲解是默认组合。用户可改用其他语言或单语；中文原稿可以原文配注释。标题与术语跟随选择的语言，保留来源中真实出现的原词，新增译名明确标注。

不同文字、从右到左排版及复杂数学需要相应字体和排版能力。捆绑脚本无法正确处理时使用适合的工具；工具不可用时说明实际限制并交付可用内容，不以“支持多语言”代替文件验证。
