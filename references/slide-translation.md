# Faithful slide translation

Use for the right panel of a slide companion. Preserve composition and instructional content; change the language of translatable text. Mathematical notation, data, plotted geometry, and object positions retain their source meaning. Different scripts cannot be pixel-identical: corresponding objects must occupy the same regions, with matching hierarchy and readable text.

## Establish correspondence

Inventory every title, text box, bullet level, footnote, table cell, graph/figure label, equation, and decorative object. Map each source text region to a translated region, retaining reading order, coordinates, dimensions, alignment, emphasis, and style. Distinguish prose from symbols, code identifiers, proper names, and data. Maintain a lecture terminology map.

Preserve source statements, conditions, emphasis, and numerical values. The translated slide contains only translated source content. Clarifications, corrections, foundations, homework references, and teacher remarks belong below both panels.

## Editable PPTX/deck

Duplicate the deck to a new file. Replace text in corresponding shapes/runs/table cells, preserving masters, slide dimensions, group transforms, layering, fills, borders, charts, equations, and object geometry. Translate chart axes/legends and image labels through an appropriate edit/redraw while preserving plotted geometry and values. Inspect grouped objects and speaker notes when in scope.

Fit translation through precise concise wording, line breaks, and glyph-complete fonts within the same region bounds and hierarchy. Do not combine boxes into one prose column. If text expansion cannot fit readably without changing layout, identify and resolve the specific region rather than claiming perfection. Export source and translated decks using identical page settings; inspect both. Deliver an editable translated PPTX only if actually created and requested.

## PDF-only

Prefer page/object-aware reconstruction. Retain page geometry and graphics while replacing corresponding text. Masking must restore the actual background and preserve axes, gridlines, formulas, table rules, and diagrams; a white rectangle over colored content is not faithful reconstruction. Inspect every edited region.

Keep equations as source graphics where possible; translate surrounding prose/labels. Reconstructed math must preserve structure, symbols, signs, fraction bars, and indices. Extraction alone is not equation verification.

## Scans and flattened images

Use OCR plus visual verification, then reconstruct translatable regions with graphics and page dimensions retained. Check each number/symbol against the image and mark unreadable locations. If available tools cannot replace text without damage or read the input, report the precise blocker and prepare usable content. A labeled reflow edition requires the learner's explicit choice.

## Pair and annotate

The bundled renderer takes an original PDF and an already translated PDF. Counts and corresponding visible dimensions must agree; both panels use equal viewports and shared scale. Those geometric checks cannot prove the translation's internal object fidelity.

Put all added terminology, foundation notes, classroom remarks with locators, homework references, corrections, and guide links in a full-width bottom band. Keep notes short and send longer explanations to precise guide sections. Retain N companion pages for N originals: enlarge sheet space or use the guide instead of extra companion pages or tiny text.

## Verify every pair

Compare titles, bullet hierarchy, text boxes, tables, figures, axes/legends, values, equations, colors, and footnotes region by region. Check omissions, untranslated labels, duplicated source prose, wrong emphasis, substituted fonts, clipping, overlap, and lost background details. Confirm added teaching stays outside both panels. Report unresolved regions; page-count equality alone does not establish fidelity.
